# Vada — المشروع الكامل مع كل التعديلات

## ماذا يوجد هنا؟
مشروع Android كامل + كل التحسينات:

### التحويل Office → PDF
- طباعة (Print to PDF) — موصى بها
- لقطة شاشة داخلية — غالباً حجم أصغر
- ضغط تلقائي لحجم الملف الناتج

### إصلاحات
- جداول وصور DOCX، أسماء شيتات Excel، PPTX
- استرجاع المهام، SharedImport، شفافية الصور
- إزالة force-unwrap الخطرة

### تجربة المستخدم
- شبكة رئيسية عمودين، ScreenHeader، خطوات مرقّمة
- اختيار جودة الضغط كأزرار أفقية

## البناء
افتح المجلد في Android Studio أو:
```bash
./gradlew :app:assembleDebug
```
